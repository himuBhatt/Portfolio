# Himanshu&#39;s Portfolio

A modern portfolio website built with Vite, React, TypeScript, Tailwind CSS and shadcn/ui.

## Quick Start

```sh
# Clone the repo
git clone <repo-url>
cd Portfolio-Himanshu-main

# Install dependencies
npm install

# Start dev server
npm run dev
```

Open http://localhost:3000 to view.

## Technologies

- Vite (build tool)
- React + TypeScript
- Tailwind CSS
- shadcn/ui components
- 3D elements with Three.js (optional)

## Deployment

Deploy to:
- Vercel: Connect GitHub repo
- Netlify: Drag/drop build folder or Git
- GitHub Pages: `npm run build`, deploy dist/

## Scripts

- `npm run dev` - Development server
- `npm run build` - Production build
- `npm run lint` - Lint code
- `npm run preview` - Preview production build
